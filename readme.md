# Sound Wave Rhythm

An interactive, high-performance HTML5 and WebGL real-time audio visualization platform. Built for responsiveness, speed, and privacy-first audio processing.

## 🚀 Features

- **Real-Time Visualization:** Captures audio from the device microphone via the Web Audio API and analyzes frequency distribution using the Fast Fourier Transform (FFT).
- **Stunning WebGL Renderers:** Renders animations using low-overhead WebGL fragment and vertex shaders. Features 8 unique visualizer algorithms including Radial waves, Classic spectrum, and retro stepped vúmeters.
- **Responsive Theme:** Fully optimized for mobile, tablet, and desktop viewports using a premium dark glassmorphism design system.
- **Privacy-First:** Audio signals are processed completely locally in the browser and never transmitted to external servers.

## 🌐 Project Structure

- `index.html`: The main landing page, hosting the interactive WebGL audio visualizer and detailed educational text about sound wave physics and browser APIs.
- `privacy-policy.html`: Google AdSense compliant privacy policy detailing cookies and local microphone processing.
- `ads.txt`: AdSense publisher identification.
- `css/styles.css`: Centralized stylesheet with full styling tokens, navbar, footer, layout cards, and responsive media queries.
- `js/index.js`: WebGL context initialization, canvas render loop, and Web Audio API microphone setup.
- `js/animations.js`: Animation definitions and HSL-to-RGB color logic.
